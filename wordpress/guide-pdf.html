Moto's Cool · Mettre le site dans WordPress

Guide pas à pas · à suivre dans l'ordre · environ 10 minutes

Avant de commencer, il faut :
  1. le fichier motoscool-theme.zip (54 Mo) → ne PAS le décompresser ;
  2. l'identifiant et le mot de passe WordPress du patron (compte administrateur) ;
  3. l'adresse qui recevra les demandes de rendez-vous : contact@motoscool.fr (déjà réglée). Autre adresse possible uniquement en @motoscool.fr ; pour toute autre adresse (Gmail, Hotmail, Outlook, Orange, Yahoo, iCloud…), prévenir SYZ avant.
Sur un Mac : télécharger le zip avec Chrome (Safari le décompresse parfois tout seul).

1. Se connecter

  1. Dans le navigateur, taper : motoscool.fr/wp-admin
  2. Entrer l'identifiant et le mot de passe du patron, cliquer Se connecter.

2. Installer le site

  1. Menu de gauche : Apparence → Thèmes.
    Noter le nom du thème actif actuel (pour pouvoir revenir en arrière).
  2. En haut : Ajouter un thème, puis en haut : Téléverser un thème.
  3. Choisir un fichier → prendre motoscool-theme.zip → Installer maintenant → attendre 1 à 2 minutes.
  4. Quand « Thème installé avec succès » s'affiche : Activer.
  5. Si une extension de cache existe (WP Rocket, LiteSpeed…) : Vider le cache.

3. Régler la réception des demandes

  1. Menu de gauche : Réglages → Moto's Cool RDV.
  2. « Email de l'accueil » : vérifier contact@motoscool.fr (ou taper l'adresse complète choisie). Laisser « Expéditeur » vide. Une adresse vide ou incomplète est refusée avec un message ; l'ancienne est gardée.
  3. Cliquer Enregistrer les modifications.
  4. Cliquer Envoyer un email de test à l'accueil → vérifier qu'il est bien reçu (regarder aussi les indésirables / spams).

4. Vérifier que tout marche

  1. Ouvrir motoscool.fr : le nouveau site Moto's Cool s'affiche.
  2. Faire une vraie demande de rendez-vous sur le site (formulaire en haut de la page).
  3. L'accueil reçoit l'email « NOUVELLE DEMANDE DE RDV — jour date à heure — nom ». « Répondre » à cet email écrit directement au client.
  4. Dans cet email : cliquer Libérer la place de ce créneau, puis le bouton Libérer la place → le créneau de test redevient libre.

✔ C'est terminé.

Si quelque chose bloque

Après « Installer maintenant » : « Le lien que vous avez suivi a expiré » ou un message parlant de « upload_max_filesize »Limite de l'hébergement OVH. Ne rien forcer : appeler SYZ. (Méthode de secours : FileZilla → dossier www/wp-content/themes → y glisser le dossier « motoscool » extrait du zip → WordPress : Apparence → Thèmes → Moto's Cool → Activer.)
L'email de test n'arrive pasVérifier d'abord l'adresse de l'accueil (étape 3). Puis : Extensions → Ajouter → WP Mail SMTP → Installer → Activer → « Autre SMTP » : serveur smtp.mail.ovh.net, chiffrement SSL, port 465, identifiant = l'adresse de l'accueil (contact@motoscool.fr), mot de passe = celui de cette boîte (tapé par le patron), e-mail d'expédition = la même adresse, et cocher la case « Forcer… » juste en dessous. Enregistrer, puis refaire l'email de test.
Boîte OVH « Email Pro » ou « Exchange » : le serveur SMTP est différent (indiqué dans l'espace client OVH).
L'email de test arrive, mais la demande de RDV affiche « L'envoi n'a pas abouti »Espace client OVH → Web Cloud → Hébergements web → l'hébergement → Vue d'ensemble → PHP → « Modifier la version de PHP » → Options avancées → Pare-feu applicatif : désactivé → Valider. Puis onglet « Mes sites » → motoscool.fr (puis www.motoscool.fr) → Gérer mes domaines → Gérer mes options → décocher « Activer le firewall » → Confirmer.
Une page s'affiche sans mise en formeVider le cache, puis Réglages → Permaliens → Enregistrer les modifications.
Revenir à l'ancien siteApparence → Thèmes → réactiver l'ancien thème (rien n'est supprimé).
