1. Installer la nouvelle version

  1. motoscool.fr/wp-admin → se connecter.
  2. Apparence → Thèmes → Ajouter un thème → Téléverser un thème.
  3. Choisir un fichier → motoscool-theme-leger.zip (0,8 Mo, ne pas le décompresser) → Installer maintenant.
  4. WordPress dit que le thème est déjà installé : cliquer Remplacer l'actuel par la version téléversée.
  5. « Le thème a bien été mis à jour » : cliquer Tableau de bord (menu de gauche). La page « Installation du site Moto's Cool » s'ouvre seule et monte jusqu'à 100 % (1 à 2 min) : ne pas la fermer.
    Si à la place un bouton rouge « Terminer l'installation du site » apparaît : cliquer dessus.
  6. Fin : la page Moto's Cool RDV s'ouvre avec « Site Moto's Cool installé ». Les 17 pages « Moto's Cool – … » sont à jour (ancienne version gardée dans l'historique d'Elementor) ; les anciennes pages du garage ne bougent pas.
  7. Si une extension de cache existe (WP Rocket, LiteSpeed…) : Vider le cache.

2. Vérifier les réglages (Réglages → Moto's Cool RDV)

  1. Email de l'accueil : contact@motoscool.fr. WhatsApp et mobile du dépanneur : 06 33 66 04 10. Lien des avis Google, lien TikTok.
  2. Enregistrer les modifications, puis Envoyer un email de test à l'accueil → vérifier la réception (et les spams).

3. Vérifier que tout marche

  1. Ouvrir motoscool.fr sur l'ordinateur et sur un téléphone : le site s'affiche, le bouton « Une question ? » ouvre l'assistant.
  2. Faire une vraie demande de rendez-vous avec votre propre email : l'accueil reçoit « NOUVELLE DEMANDE DE RDV… », et vous recevez « Votre demande de rendez-vous est bien reçue ».
  3. Dans l'email de l'accueil : Libérer la place de ce créneau → Libérer la place.

Moto's Cool · Modifier son site (pour le garage)

Tout se fait dans motoscool.fr/wp-admin, comme pour l'ancien site. Les anciennes pages restent dans la liste mais ne s'affichent plus.

Les pages du site

  1. Pages : chaque page du site a sa ligne « Moto's Cool – … » (Accueil, Entretien & révision, Dépannage moto, Zone Paris…).
  2. Survoler la ligne → Modifier avec Elementor.
  3. Cliquer sur une partie de la page : à gauche, ses champs s'affichent.
    • Textes (titres, paragraphes, boutons) : taper le nouveau texte, l'aperçu change aussitôt.
    • Photos : cliquer sur la photo du champ → Médiathèque ou Téléverser des fichiers → Insérer le média.
    • Listes (questions de la FAQ, photos de l'atelier, liens…) : Ajouter un élément, glisser pour changer l'ordre, icône poubelle pour retirer.
    • Liens : adresse d'une page (ex. /services/depannage.html), d'un téléphone (tel:+33143762638) ou d'un site.
    • Code HTML (avancé) : en bas des champs, « Modifier le code de ce bloc » → Oui : le code remplace le bloc.
  4. Ajouter : glisser un élément Elementor (Titre, Texte, Image, Vidéo…) ou un bloc « Moto's Cool · Texte » à l'endroit voulu. Retirer une partie : clic droit → Supprimer (le reste du site continue de fonctionner).
  5. Toujours finir par Mettre à jour (en bas à gauche). Historique (icône horloge) : revenir à une version précédente.

En-têtes et pieds de page

Modèles → Modèles enregistrés → « Moto's Cool – En-tête (…) » ou « Pied de page (…) » → Modifier avec Elementor. Une seule modification s'applique à toutes les pages concernées (page d'accueil · pages services et zones · pages légales).

Vidéos

  1. 4 films 3D de l'atelier sont déjà en place : les garder, les retirer (survoler → Corbeille) ou en ajouter. Sans vidéo publiée, la partie Vidéos et son lien du menu disparaissent du site.
  2. Menu Vidéos → Ajouter une vidéo → titre (affiché sous la vidéo).
  3. Un fichier : Choisir → Envoyer la vidéo (toutes les tailles passent ; MP4 conseillé) — ou un lien YouTube / TikTok.
  4. Publier : la vidéo apparaît dans la partie « Vidéos » de l'accueil. Ordre : « Attributs → Ordre » (0 = en premier).

Titre, description et mot-clé de chaque page sont déjà remplis. Pour les changer : dans Elementor, bouton SEO (Rank Math) en haut du panneau, ou colonnes « Titre SEO / Description SEO » de la liste Pages.

Emails : éviter les spams (à faire par SYZ avec le patron, une seule fois)

  1. WP Mail SMTP : Extensions → Ajouter → « WP Mail SMTP » → Installer → Activer → « Autre SMTP » : serveur ssl0.ovh.net, SSL, port 465, identifiant contact@motoscool.fr + mot de passe (tapé par le patron), expéditeur contact@motoscool.fr, cocher « Forcer » → Envoyer un email de test.
  2. DKIM : espace client OVH → Web Cloud → Emails → motoscool.fr → DKIM → Activer (jusqu'à 24 h).
  3. DMARC : espace client OVH → Noms de domaine → motoscool.fr → Zone DNS → Ajouter une entrée → TXT : sous-domaine _dmarc, valeur v=DMARC1; p=none;
